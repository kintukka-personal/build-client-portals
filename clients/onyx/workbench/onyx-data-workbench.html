Stage 02

Read every column before trusting one

The workbench walks each column cell by cell: what is filled, what type each value really is, how many distinct values there are, and whether the column is a fixed vocabulary you can pivot on or prose you have to interpret.

Stage 03

Give each column a job

Every gym exports different headings. The workbench guesses a role for each column from its name and its shape; you correct anything it got wrong once, and the same mapping runs every month after that.
